# ADR-0002: Cache 跨节点提交原子性边界

- 状态：accepted
- 日期：2026-10-01（整理落档；决策自 2026-09-19 起生效）
- 决策者：维护团队

## 背景

`cache` 数据面在复制（ISR）路径上**跨节点提交不是原子的**：

- **本地**提交是原子的（幂等键 + 数据 + 序列号同一事务），随后才推送 ISR
  （`ensure_isr`）；
- 推送 / `min_isr` 失败时 RPC 返回错误，但**本地写入已生效**——调用方不能把错误
  读作「未写入」；
- 落后副本不是永久落后：心跳检测到落后即触发 `pull_and_catch_up` → Reconcile，
  复制日志无上限保留；不一致窗口是「Leader 提交后、Follower 补齐前」的**暂时**状态。

## 决定

把「跨节点提交原子性」**显式声明为边界**（不实现恢复语义）：不承诺跨节点原子提交；
对外契约（cache 服务 proto 的边界声明）与实现（`cache.rs` 模块头、`replicated_write`
文档）逐字一致地写明该边界。

## 后果

- `cache` 默认关闭（见 ADR-0001）；显式启用者接受该边界。
- 写路径错误语义固定为「可能已写入」，调用方需自行幂等/去重。
- 若未来提供跨节点原子提交，需新增 ADR 超越本边界。
