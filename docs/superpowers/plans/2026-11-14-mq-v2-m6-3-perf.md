- 阈值只作本机回归下限，不写成 SLO/跨机承诺；未跑项留在报告 §7。

## Review Focus

- **浸泡的正确性判据是 offset 集合**：每分区 `0..published-1` 恰好一次；committed == published；lag 0。重复投递是 at-least-once 的正常形态，按 offset 去重后仍必须全覆盖。
- **RSS 不是泄漏判据**：夹具在进程内跑状态机且保留 7 天 + idempotency 索引；10 分钟线性增长是容量行为。泄漏检测需要真实进程与稳态窗口（报告 §7 声明）。
- **再平衡允许成员分到 0 个分区**：4 分区 / 3 成员时 `2/2/0` 是稳定态；判据是「每个分区恰好分配一次」而不是「每个成员非空」。
- **基准数字有 10–15% 抖动**：报告记录运行次数与取值口径，阈值留足余量（基线 ×0.6）。
- **fsync 竞争**：浸泡与基准不得并发跑，否则数字无意义。
